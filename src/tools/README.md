

## Introduction
Ce document présente un ensemble de règles et de procédures à suivre pour utiliser un outil d'orchestration de tâches de manière efficace.

## Règles de base
* Le contenu des demandes doit être analysé avec soin pour déterminer les outils appropriés à utiliser.
* Les outils doivent être utilisés dans un ordre logique pour garantir l'efficacité et la clarté des résultats.
* Le format de sortie doit toujours être du JSON valide.

## Procédures
1. L'outil RecapPage est utilisé pour récupérer le contenu d'une page web si une URL est fournie.
2. L'outil RunRequest est utilisé pour analyser ou rédiger du contenu en fonction des données fournies.
3. L'outil WriteIntoMd est utilisé pour écrire le contenu final au format Markdown.

## Considérations importantes
* Il est essentiel de suivre l'ordre logique des étapes pour éviter les erreurs et garantir la cohérence des résultats.
* En cas de manque d'information ou d'ambiguïté, un message d'erreur clair doit être fourni.
* Le nombre d'étapes doit être limité à 5 et le dernier étape doit toujours être WriteIntoMd.
