# Skill — Parler en Verlan

## Objectif

Transformer automatiquement des mots ou expressions françaises en verlan, tout en gardant un style naturel, fluide et crédible.

---

## Règles du Verlan

### 1. Inversion des syllabes

Le principe principal du verlan consiste à inverser les syllabes d’un mot.

| Français | Verlan |
| -------- | ------ |
| femme    | meuf   |
| bizarre  | zarbi  |
| lourd    | relou  |
| arabe    | beur   |
| énervé   | vénère |
| fou      | ouf    |
| métier   | tiékar |
| pourri   | ripou  |

---

### 2. Adaptation phonétique

Le verlan ne suit pas toujours une inversion exacte.
Le résultat doit sonner naturellement à l’oral.

Exemples :

* femme → meuf
* lourd → relou
* chinois → noich
* musique → zicmu (rare)

---

### 3. Niveau de langage

Le ton doit être :

* urbain
* détendu
* oral
* crédible
* moderne

Éviter :

* les phrases trop soutenues
* le verlan forcé sur chaque mot
* les créations incompréhensibles

---

## Utilisation naturelle

Le verlan doit être utilisé avec modération.

### Exemple naturel

> Ce mec est vraiment relou aujourd’hui.

### Exemple mauvais

> Ce keum est vraiment loure aujourd’hui.

---

## Expressions fréquentes

| Expression normale | Version verlan       |
| ------------------ | -------------------- |
| c’est fou          | c’est ouf            |
| il est lourd       | il est relou         |
| ma femme           | ma meuf              |
| un arabe           | un beur              |
| un mec             | un keum              |
| tranquille         | trankil / tranquille |
| énervé             | vénère               |
| bizarre            | zarbi                |
| police             | keufs                |
| français           | céfran               |

---

## Consignes de génération

Quand tu transformes un texte :

1. Ne verlanise pas tous les mots.
2. Garde la phrase compréhensible.
3. Priorise les expressions réellement utilisées.
4. Respecte le contexte social et le ton.
5. Préserve la fluidité orale.

---

## Exemples de transformation

### Standard

> Cette femme est vraiment bizarre.

### Verlan naturel

> Cette meuf est vraiment zarbi.

---

### Standard

> Il est énervé parce que ce type est lourd.

### Verlan naturel

> Il est vénère parce que ce keum est relou.

---

## Mode avancé

Tu peux aussi :

* mélanger argot + verlan
* adapter le niveau de rue
* rendre le ton plus parisien
* générer des dialogues réalistes
* traduire du français standard vers du français urbain

---

## Style attendu

Le résultat doit ressembler à :

* une conversation réelle
* un message vocal
* un échange entre potes
* du français urbain moderne

Pas à :

* un dictionnaire mécanique
* une inversion automatique de syllabes
* un texte caricatural

---

## Exemple final

### Input

> Cette femme est énervée parce que son voisin est bizarre.

### Output

> Cette meuf est vénère parce que son voisin est zarbi.
